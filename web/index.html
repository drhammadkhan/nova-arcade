A retro games console for the ESP32-S3 2.8″ board. Flash it from your browser, drop games onto the SD card and play with a Bluetooth controller.

Your browser can't talk to USB devices. Open this page in Chrome or Edge on a computer. Browser flashing needs a secure (https) page. ⬇ SD card pack 🎮 Play in your browser

Version __VERSION__ · Chrome or Edge on desktop · USB-C data cable

Get playing in 3 steps

About five minutes, no software to install.

Flash the launcher

Plug the board into your computer, press Install on my board above and pick the USB port. If it won't connect, hold BOOT, tap RST, release BOOT and try again.

Load the SD card

Download the SD card pack, unzip it and copy the arcade folder to the root of a FAT32 microSD card. Put the card in the board.

⬇ nova-arcade-sd-card.zip

Pair and play

On a Stadia controller in Bluetooth mode, hold Y + Stadia for 2 seconds. Pick a game with the D-pad and press A. The first launch of each game takes a few seconds to install.

The games

Ten games with original art and music, in the spirit of the classics. Each has Easy, Normal and Hard: pick one on the title screen with ↑/↓. Slower is easier, and each difficulty keeps its own hi-score on the board. No board yet? Play them all in your browser, on a computer or a phone.

Hardware

Built and tested on the LCDWIKI ES3N28P / ES3C28P board.

BoardESP32-S3, 16 MB flash, 8 MB PSRAM
Screen2.8″ ILI9341 IPS, 320×240
SoundES8311 codec + speaker
StoragemicroSD (FAT32)
ControllerBluetooth LE gamepad

Controllers that work (the ESP32-S3 only has Bluetooth LE):

  • Google Stadia controller, converted to Bluetooth mode
  • Xbox Wireless controller, firmware v5 or newer
  • Other BLE gamepads supported by Bluepad32

Classic-Bluetooth pads (PS4/PS5, Switch Pro, 8BitDo) won't pair with the S3.

Make your own game

Every game is a normal Arduino sketch built on the shared ArcadeCore engine.

  • Strip renderer with DMA, sprites, text and palette effects
  • Chiptune synth with songs and sound effects
  • Controller input, pause menu, volume and hi-score saving built in
  • A desktop simulator for testing without the board

Read the guide →

To add a game to your console, copy its files into /arcade on the SD card:

  • MyGame.bin the compiled sketch (required)
  • MyGame.png a 160×120 thumbnail
  • MyGame.txt title, description and save id, one per line

Troubleshooting

The install button doesn't find my board

Use a USB cable that carries data, not a charge-only one. Hold BOOT, tap RST, release BOOT, then try again. Close anything else using the serial port, such as the Arduino IDE's Serial Monitor.

"Insert SD card" or "No games found"

The card must be FAT32 and contain a folder called arcade at the top level with the .bin files inside. Press A on the board to scan again.

The controller won't connect

Only Bluetooth LE controllers work. A Stadia controller must first be switched to Bluetooth mode. Flashing the launcher clears old pairings, so pair again with Y + Stadia.

Glitches or sparkles on the screen

The display speed is set in lib/ArcadeCore/src/arcade/Config.h (TFT_SPI_HZ). 27 MHz is safe on the tested board.
